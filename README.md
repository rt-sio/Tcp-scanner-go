# Fast TCP Port Scanner in Go

Простой, быстрый и эффективный многопоточный сканер TCP-портов, написанный на языке **Go**. Проект разработан на основе концепций сетевого программирования и книги *Black Hat Go*.

Инструмент использует пул воркеров (Worker Pool) и конкурентность на базе горутин (`goroutines`) и каналов (`channels`), что позволяет сканировать порты значительно быстрее последовательных аналогов.

## 🚀 Особенности

- **Высокая скорость:** Многопоточная обработка с использованием пула из 100 воркеров.
- **Устойчивость к зависаниям:** Контроль сетевых соединений с помощью `net.DialTimeout` (тайм-аут 2 секунды).
- **Простота использования:** Интерактивный ввод целевого домена или IP-адреса.

## 🛠️ Как это работает

1. Программа запрашивает у пользователя целевой домен или IP-адрес.
2. Инициализируется буферизированный канал задач на 100 портов и запускается 100 конкурирующих воркеров.
3. Отдельная горутина генерирует список портов для проверки (от 1 до 1024) и отправляет их в канал.
4. Воркеры перехватывают задачи, пытаются установить TCP-соединение и отправляют результат обратно.
5. Главный поток собирает открытые порты и выводит их список вместе с общим временем работы.

## 📋 Требования

- Установленный [Go](https://go.dev) версии 1.18 или выше.

## 💻 Запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd tcp-scanner-go
   ```

2. Запустите программу:
   ```bash
   go run main.go
   ```

3. Введите целевой адрес (например, `localhost` или `scanme.nmap.org`):
   ```text
   Введите целевой хост или IP-адрес (например, google.com или 192.168.1.1):
   localhost
   ```
